# Nyrna UX / 新功能优化选项（2026-02-10）

## 目标
- 提升日常高频操作效率，减少误操作成本，增强稳定性与可恢复性。
- 在不显著增加维护负担的前提下，优先选择高价值、低复杂度改进。

## 评估维度
- 用户价值：是否显著改善高频路径（暂停/恢复/切换/定位目标进程）。
- 实现复杂度：跨平台差异、状态管理复杂度、测试成本。
- 风险：是否引入误杀、错误状态、不可预期自动化行为。
- 可验证性：是否有可量化指标（成功率、操作步数、误触率）。

## 候选项（可选）

### 1) 操作安全层（Kill 二次确认 + 5 秒撤销）
- 内容：`Kill process` 增加确认弹窗；执行后给 snackbar 提供短时撤销入口（可选仅恢复 UI 状态，不承诺进程可恢复）。
- 价值：显著降低误触 Kill 风险。
- 复杂度：低。
- 推荐度：高。

### 2) 快捷操作层（卡片内 Quick Actions）
- 内容：卡片 hover/选中时直接展示 `Suspend/Resume`、`Kill`、`Details` 快捷按钮，减少进入三点菜单的步骤。
- 价值：高频操作提速。
- 复杂度：中。
- 推荐度：高。

### 3) 任务视图层（分组与批量操作）
- 内容：按 executable 分组展示，组级别一键 `Suspend all` / `Resume all` / `Kill all`（Kill all 需强确认）。
- 价值：多实例应用场景提升明显。
- 复杂度：中。
- 推荐度：中高。

### 4) 自动化规则层（条件触发）
- 内容：支持简单规则，如“窗口失焦后 X 秒自动 suspend”“恢复后自动置顶/激活”等。
- 价值：重度用户收益大。
- 复杂度：高。
- 推荐度：中。

### 5) 状态可观测性层（操作结果面板）
- 内容：新增最近操作日志面板（成功/失败、原因、PID、耗时），支持一键复制诊断信息。
- 价值：降低排障成本，改善“为什么失败”反馈。
- 复杂度：低到中。
- 推荐度：高。

### 6) 首次体验层（Onboarding 向导）
- 内容：首次启动引导：热键设置、最小化策略、托盘行为、隐藏规则。
- 价值：新用户上手更快。
- 复杂度：中。
- 推荐度：中高。

### 7) 平台能力感知层（依赖与限制提示升级）
- 内容：更明确提示 X11/Wayland 差异、缺失依赖、权限不足场景，并给出一键修复建议。
- 价值：减少“功能不可用但不知原因”的挫败感。
- 复杂度：低。
- 推荐度：高。

## 推荐组合（给你直接选）

### A. 快速收益包（推荐）
- 包含：`1 + 5 + 7`
- 适合：希望尽快提高可用性与稳定感，风险最低。
- 预计周期：短。

### B. 效率提升包
- 包含：`2 + 3`
- 适合：目标是高频操作效率和批量管理能力。
- 预计周期：中。

### C. 高级自动化包
- 包含：`4 + 6`
- 适合：面向重度用户，强调“少操作、强编排”。
- 预计周期：中到长。

## 迭代顺序建议
1. 先做 `A`（快速降低误触与排障成本）。
2. 再做 `B`（明显提升日常操作效率）。
3. 最后做 `C`（高价值但复杂，放到能力成熟阶段）。

## 成功指标（上线后观察）
- 误触/误杀反馈数下降。
- 平均完成一次 suspend/resume 的点击步数下降。
- “操作失败但无原因”类 issue 占比下降。
- 日活用户中的功能使用深度（批量/快捷操作渗透率）上升。

## 第二轮（更激进）功能候选
你说前一版不满意，这里给一组更“产品化差异”而不是常规 UI 微调的方向。

### 8) 场景快照（Session Snapshot）
- 内容：一键保存当前“被暂停集合 + 顺序 + 窗口状态”，下次可整体恢复。
- 价值：把 Nyrna 从单点工具升级成“会话管理器”。
- 复杂度：中高（跨平台窗口还原一致性）。
- 适用：多任务/多游戏切换用户。

### 9) 智能候选建议（Smart Target Suggestion）
- 内容：自动高亮“最可能需要暂停”的进程（高 CPU/前台失焦/全屏切换等信号）。
- 价值：减少用户寻找目标的认知成本。
- 复杂度：中。
- 风险：误判；需要可关闭和可解释理由。

### 10) 恢复保护模式（Safe Resume Ramp）
- 内容：恢复时支持“渐进恢复”：先主进程，再子进程，间隔数百毫秒，避免一次性恢复卡顿。
- 价值：降低恢复瞬时卡顿和失败概率。
- 复杂度：中。
- 适用：大型游戏或多子进程应用。

### 11) 冲突检测中心（Conflict Inspector）
- 内容：检测可能冲突的软件与环境（overlay、反作弊、输入映射、Wayland 限制），并提示风险级别。
- 价值：把“玄学失败”变成可解释问题。
- 复杂度：中。
- 适用：问题定位、减少 issue 噪音。

### 12) 操作回放（Action Replay）
- 内容：记录最近 N 次 suspend/resume/kill 序列，允许一键重放（可编辑）。
- 价值：半自动化能力，介于手工和规则引擎之间。
- 复杂度：中高。
- 风险：错误重放；需确认机制。

### 13) “游戏模式”专用面板（Game Mode Board）
- 内容：只展示游戏相关进程，提供超大按钮 + 手柄友好导航 + 低干扰布局。
- 价值：在客厅/串流场景有明显体验优势。
- 复杂度：中。
- 适用：Moonlight/手柄用户。

### 14) 失败自愈策略（Self-Healing Retries）
- 内容：当 suspend/resume 失败时按策略自动重试（含不同策略分支），并给出最终原因。
- 价值：提高成功率，减少“点一下没反应”。
- 复杂度：中。
- 风险：重试过度导致副作用；需限次和可观测。
